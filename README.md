# 🏃‍♂️⚡️ StrideSync Web — Athletic Intelligence & GPS Running App Landing Page

Official promotional and interactive preview web application for **StrideSync iOS**, built with React 18, Vite, Tailwind CSS, and Lucide Icons.

![StrideSync Banner](/public/app-icon.png)

## 🚀 Fitur Unggulan Website

- 📱 **Interactive Multi-Tab iPhone Mockup**: Live HUD telemetry, Community Feed with Kudos, Climb Classifier, dan Banister TRIMP Recovery Gauge.
- 🫁 **Live VO2 Max & Race Predictor Calculator**: Hitung estimasi kapasitas aerobik dan waktu finish 10K, Half Marathon, dan Marathon secara interaktif.
- 🎙️ **Audio Voice Coach Preview**: Simulasi instruksi suara AI Coach saat sesi latihan.
- 🎨 **Sleek OLED Athletic Theme**: Menggunakan palet resmi Strava/StrideTheme (`#FC5200` Neon Orange, `#2ECC71` Athletic Green).
- ⚡️ **Ultra Fast Performance**: Ditenagai oleh Vite & Tailwind CSS.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Confetti Animation**: Canvas Confetti

## 💻 Cara Menjalankan Secara Lokal

```bash
# 1. Masuk ke folder proyek
cd stridesync-web

# 2. Install dependensi
npm install

# 3. Jalankan development server
npm run dev
```

Buka `http://localhost:3000` di browser Anda.

## 🚢 Deploy ke Vercel / Netlify

Website ini siap dideploy langsung ke **Vercel** atau **Netlify** hanya dengan menghubungkan repository ini.
